# BeeMap documentation

BeeMap is a public map for honeybees and wild bees in Heilbronn: Asian hornet detection and nest finding with smart hives, fair hive siting, flower gaps and what to plant, and pollen and weather sensors. It is a proof of concept for the Green City Hackathon Heilbronn.
